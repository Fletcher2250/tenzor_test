
# Тестовое задание Тензор

## Описание проекта

Проект представляет собой автоматизированные UI-тесты веб-интерфейса Яндекса с использованием Python, Selenium WebDriver и Pytest.

**Компания:** Тензор  
**Основная роль:** Тестирование  
**Язык программирования:** Python 3.13

## Ссылка на задание

[Тестовое задание Тензор](ВСТАВИТЬ_ССЫЛКУ_НА_ИСХОДНОЕ_ЗАДАНИЕ)

## Что реализовано

### 1. Проверка поиска

- Открытие главной страницы Яндекса.
- Ввод поискового запроса «Тензор».
- Проверка введённого значения.
- Ожидание появления поисковых подсказок.
- Переход к результатам поиска.
- Проверка, что первый найденный не рекламный результат ведёт на `tensor.ru`.

### 2. Проверка Яндекс.Картинок

- Открытие страницы Яндекс.Картинок.
- Открытие первого изображения.
- Проверка загрузки изображения.
- Переход к следующему изображению.
- Возврат к предыдущему изображению.
- Проверка возврата к исходному изображению.

## Что не реализовано

- Проверка других поисковых запросов.
- Проверка всех результатов поиска.
- Проверка всех изображений в галерее.
- Нагрузочное тестирование.
- Автоматический запуск тестов через CI/CD.

Данные задачи не выполнялись в рамках выбранного объёма работы.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/Fletcher2250/tenzor_test.git
cd tenzor_test
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

### 3. Активация виртуального окружения (Windows)

```bash
.venv\Scripts\activate
```

### 4. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 5. Запуск всех тестов

```bash
pytest -v
```

### 6. Запуск отдельных тестов

Тест поиска:

```bash
pytest -v tests/test_search.py
```

Тест Яндекс.Картинок:

```bash
pytest -v tests/test_images.py
```

## Как проводилась проверка

Для проверки использовались Selenium WebDriver и Pytest.

Тесты запускались локально в браузере Google Chrome.

В процессе проверки использовались явные ожидания Selenium для загрузки элементов страницы и выполнения действий.

Последний результат локального запуска:

```text

tests/test_search.py::test_search_tensor_is_first_result PASSED

2 passed
```
